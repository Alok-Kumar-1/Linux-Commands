# Linux Commands 🔥
A beginner-friendly and well-organized collection of Linux commands with explanations and examples.

This repository contains my practice while learning basic Linux commands.

## Topics Covered

* File and directory management
* File viewing and editing
* Permissions and ownership
* Process management
* Package management
* Basic system commands

## Common Commands Practiced

List files

```
ls
```

Change directory

```
cd
```

Create file

```
touch filename
```

Create directory

```
mkdir directory_name
```

Remove files or directories

```
rm filename
rm -r directory_name
```

Copy files

```
cp source destination
```

Move or rename files

```
mv oldname newname
```

View file content

```
cat filename
less filename
```

Check running processes

```
ps
top
```

Change file permissions

```
chmod
```

## Purpose

This repository was created to practice and understand commonly used Linux commands for development and DevOps environments.
